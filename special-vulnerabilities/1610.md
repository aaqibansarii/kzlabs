# Title

Local File Inclusion (LFI) via Base64-Encoded File Path

## Vulnerability Type

Local File Inclusion (LFI)

## Summary

The application provides a **Recipe File Explorer** in the **About** section that accepts a Base64-encoded file path and reads the corresponding file from the server.

By supplying a Base64-encoded path to a local file, the backend decodes the input and returns the file contents in the response.

The vulnerability was confirmed by reading the `/etc/hosts` file.

## Vulnerable Endpoint

```http
https://kzlabs.in/1610.php
```

### Vulnerable Parameter

```http
f
```

## Steps to Reproduce

1. Navigate to the **About** page.
2. Enter the Base64-encoded value of the target file path.

```text
L2V0Yy9ob3N0cw==
```

3. Click **Open**.
4. Observe that the application decodes the supplied value and returns the contents of the local file.
5. This confirms that arbitrary local files can be read from the server.

## Payload Used

```text
L2V0Yy9ob3N0cw==
```

## Impact

* Disclosure of sensitive server files
* Information leakage about the underlying operating system
* Exposure of configuration files and credentials
* Potential chaining into further attacks

## Recommendations for Fix

* Restrict file access to an allowlisted directory
* Validate and sanitize user-supplied file paths
* Prevent access to arbitrary filesystem locations
* Return generic error messages without exposing file paths
