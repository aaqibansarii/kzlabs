# Title

Directory Listing Enabled Exposes Internal Files

## Vulnerability Type

Information Disclosure (Directory Listing)

## Summary

The application has directory listing enabled for the `/kzlabs/cdn/images/` directory, allowing unauthenticated users to browse and access the contents of the directory.

The exposed listing reveals internal filenames, file sizes, and last modified timestamps, which can aid attackers in reconnaissance and information gathering.

## Vulnerable Endpoint

```http
https://kzlabs.in/kzlabs/cdn/images/
```

## Steps to Reproduce

1. Navigate to the following URL:

```text
https://kzlabs.in/kzlabs/cdn/images/
```

2. Observe that the server displays an index of all files within the directory.
3. The directory listing exposes file names, sizes, and modification dates without authentication.

## Impact

* Disclosure of internal file structure
* Information leakage useful for reconnaissance
* Exposure of sensitive or unintended files
* May assist attackers in identifying additional attack vectors

## Recommendations for Fix

* Disable directory listing on the web server
* Return a `403 Forbidden` or `404 Not Found` response for directory requests
* Restrict direct access to internal asset directories
* Remove unnecessary or sensitive files from publicly accessible directories
