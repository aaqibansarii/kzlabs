# Title

Weak Default Credentials Allow Unauthorized Administrator Access

## Vulnerability Type

Weak Authentication / Default Credentials

## Summary

The application uses weak default administrator credentials that allow unauthorized users to access the administrative dashboard.

Authentication was successfully bypassed using the following credentials:

* **Email:** `admin@cbse.local`
* **Password:** `admin123`

## Vulnerable Endpoint

```http
https://kzlabs.in/1617.php
```

## Steps to Reproduce

1. Navigate to the login page.
2. Enter the following credentials:

```text
Email: admin@cbse.local
Password: admin123
```

3. Click **Sign In**.
4. Observe that authentication succeeds and the administrator dashboard is accessible.

## Credentials Used

```text
Email: admin@cbse.local
Password: admin123
```

## Proof of Concept

The application authenticates the user as **Administrator** and grants access to the student database and administrative functionality.

## Impact

* Unauthorized administrative access
* Exposure of sensitive student information
* Ability to perform privileged administrative actions
* Complete compromise of the application's administrative interface

## Recommendations for Fix

* Remove default credentials before deployment
* Enforce strong unique passwords for all accounts
* Require password changes on first login
* Implement account lockout and strong password policies
