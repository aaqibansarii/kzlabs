# Title

Local File Inclusion (LFI) via Document Reference Path

## Vulnerability Type

Local File Inclusion (LFI)

## Summary

The application accepts user-controlled input in the **Document Retrieval System** and uses it to retrieve files from the server.

By supplying an arbitrary file path, the backend reads and returns the contents of local files.

The vulnerability was confirmed by reading the `/etc/passwd` file.

## Vulnerable Endpoint

```http
https://kzlabs.in/1611.php
```

### Vulnerable Parameter

```http
doc
```

## Steps to Reproduce

1. Navigate to the **Documents** page.
2. Enter the following value in the **Document Reference Path** field:

```text
/etc/passwd
```

3. Click **Retrieve**.
4. Observe that the application returns the contents of the local file.
5. This confirms that arbitrary local files can be read from the server.

## Payload Used

```text
/etc/passwd
```

## Impact

* Disclosure of sensitive server files
* Information leakage about the underlying operating system
* Exposure of configuration files and credentials
* Potential chaining into further attacks

## Recommendations for Fix

* Restrict file access to an allowlisted directory
* Validate and sanitize user-supplied file paths
* Prevent access to arbitrary filesystem locations
* Return generic error messages without exposing file paths
