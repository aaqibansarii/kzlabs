# Title

Command Injection via WAF Bypass in Cloud Shell

## Vulnerability Type

Command Injection

## Summary

The application attempts to block dangerous commands using WAF rules. However, the blacklist can be bypassed by using alternative commands that achieve the same result.

The WAF blocks commands such as `cat /etc/passwd`, but allows equivalent commands like `head /etc/os-release`, demonstrating that command execution is still possible despite the WAF restrictions.

## Steps to Reproduce

1. Navigate to the **Cloud Shell** page.
2. Enter the following command:

```text id="mk74nq"
head /etc/os-release
```

3. Click **Execute**.
4. Observe that the command executes successfully and the output is displayed.
5. This confirms that WAF protections can be bypassed to execute system commands.

## Impact

* Execution of arbitrary system commands
* WAF protection can be bypassed
* Disclosure of sensitive system information
* Potential escalation to Remote Code Execution (RCE)

## Recommendations for Fix

* Do not rely on blacklist-based WAF filtering
* Implement strict allowlisting of permitted commands
* Avoid passing user input directly to system shells
* Execute commands using safe APIs without shell interpretation
