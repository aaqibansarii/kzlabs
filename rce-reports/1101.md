# Remote Code Execution (RCE) via Unsanitized `cmd` Parameter

## Vulnerability Type

Remote Code Execution (RCE)

## Summary

The application allows user-supplied input from the `cmd` parameter to be executed directly on the underlying operating system without proper validation or sanitization.

An attacker can execute arbitrary system commands on the target server, resulting in complete compromise of the affected system and unauthorized access to sensitive information.

## Vulnerable Endpoint

```http
https://kzlabs.in/1101.php?cmd=<command>
```

### Vulnerable Parameter

```http
cmd
```

## Steps to Reproduce

1. Navigate to the **Remote Command Runner** functionality.
2. Observe that commands entered into the input field are executed on the server.
3. Supply the following command:

```bash
cat /etc/os-release
```

4. Execute the command.
5. Observe that the output from the server is returned and displayed in the response panel.

## Payload Used

```bash
cat /etc/os-release
```

## Proof of Concept

The application executes the supplied operating system command and returns the command output to the user.

The response contains the contents of the `/etc/os-release` file, disclosing system information including:

* Operating System Name
* Ubuntu Version
* Distribution Information
* System Configuration Details

This confirms that arbitrary operating system commands supplied through the `cmd` parameter are executed on the server.

## Impact

* Arbitrary command execution on the server
* Disclosure of sensitive system information
* Unauthorized access to files and resources
* Potential privilege escalation
* Full server compromise
* Complete loss of confidentiality, integrity, and availability

## Recommendations for Fix

* Avoid executing user-supplied input as system commands.
* Implement strict server-side input validation and allowlists.
* Use safe APIs instead of shell command execution whenever possible.
* Apply the principle of least privilege to application processes.
* Restrict access to administrative functionality.
* Monitor and log suspicious command execution attempts.
